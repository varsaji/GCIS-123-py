# GCIS-123 — Python Codes

Coursework for **GCIS-123 (Software Development & Problem Solving)**.
Small Python programs, organized by week.

## How to run

Each file is standalone. From this folder:

```bash
python week3/vote.py
```

Most programs ask for keyboard input.

## What's inside

### Top level
| File | What it does |
|------|--------------|
| `calc.py`  | Menu calculator (+, −, ×, ÷) built with functions |
| `grade.py` | Turns a percentage into a letter grade (A–F) using `if`/`elif` |

### week-2 — functions & `return`
| File | What it does |
|------|--------------|
| `activities.py`     | Win / lose / tie from two scores (function returns a string) |
| `triangle.py`       | Classifies a triangle: equilateral / isosceles / scalene |
| `example-quiz-1.py` | "Add two numbers" practice, heavily commented — Quiz 1 prep |

### week3 — conditionals (`if` / `elif` / `else`)
| File | What it does |
|------|--------------|
| `greater-than2.py` | Which of 2 numbers is bigger |
| `greater-than3.py` | Which of 3 numbers is biggest |
| `pass-grant.py`    | Password check — access granted / denied |
| `pink.py`          | Age → life stage (infant … senior citizen) |
| `posittive-num.py` | Positive / negative / zero |
| `simple.py`        | Even or odd |
| `vote.py`          | Old enough to vote? |
